# Luxury Realty Group - Portfolio Website

## Project Overview
A fully designed multi-page luxury real estate website built with pure HTML, CSS, and JavaScript. Features a modern, responsive design with interactive elements and a luxury brand aesthetic.

## Pages

### 1. Home Page (`index.html`)
- Full-screen hero with call-to-action
- Animated statistics bar (150+ properties, 12 years, 500+ clients)
- Featured properties showcase (3 cards)
- Services overview (Rentals, Management, Relocation, Investment)
- Interactive neighbourhood grid (5 areas)
- Client testimonials section
- Contact form
- Full multi-column footer with site map

### 2. About Us (`about.html`)
- Company story with side-by-side image layout
- Core values section (Excellence, Integrity, Innovation, Personalization)
- Team members grid (4 members with photos and bios)
- "Why Choose Us" feature list with checkmarks
- CTA section

### 3. Rental Developments (`rentals.html`)
- **Filter bar** with 3 interactive dropdowns (Neighbourhood, Bedrooms, Rent)
- Real-time filtering without page reload
- Results counter
- 17 property cards in a 2-column grid
- Reset filters functionality

### 4. Property Landing Page (`setai-st-maarten.html`)
- Dedicated landing page for a luxury development
- Hero section with property visuals
- Property information bar
- Amenities section (8 features)
- Floor plans for different unit types
- Photo gallery
- Location highlights
- Contact CTA

## File Structure
```
├── index.html              # Home page (landing)
├── about.html              # About Us page
├── rentals.html            # Rental Developments with filters
├── setai-st-maarten.html   # Property landing page
├── style.css               # All styling (1000+ lines)
├── script.js               # Filter functionality
└── README.md               # This file
```

## Technical Details

- **Pure HTML/CSS/JavaScript** — zero dependencies
- **Responsive design** — desktop, tablet, and mobile
- **CSS Grid & Flexbox** — modern layout
- **Google Fonts** — Playfair Display for headings
- **Smooth transitions** — hover effects and animations
- **HTML5 form validation**

## Design

- Dark header with gold accents (#d4a574)
- Playfair Display serif font for luxury feel
- Clean typography with generous whitespace
- Professional photography via Unsplash
- Consistent branding across all 4 pages

## How to View

Open `index.html` in any browser — no build tools or server needed.

For GitHub Pages: push the repo, enable Pages in Settings, done.
